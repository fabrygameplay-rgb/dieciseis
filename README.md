# Nintendo Vintage Store 🎮⏳

> Aplicación web estática tipo e-commerce retro que recorre la historia de las consolas y videojuegos clásicos de Nintendo desde los años 80 hasta el cambio de milenio.

---

## 📋 Descripción General
**Nintendo Vintage Store** es un proyecto frontend interactivo inspirado en la nostalgia de las consolas clásicas. La interfaz permite explorar catálogos organizados por generaciones de hardware (NES, SNES, N64, GameCube, Game Boy, Game Boy Color), gestionar un carrito de compras y simular el flujo de autenticación de usuarios de forma dinámica.

---

## 🚀 Características Principales
* **Catálogo Histórico por Consolas:** Secciones dedicadas a NES (1985), SNES (1990), N64 (1996), GameCube (2001), Game Boy (1989) y Game Boy Color (1998).
* **Simulación de E-Commerce:** Botones interactivos de "Buy" (Comprar) y "Add to cart" (Añadir al carrito) con gestión de productos.
* **Autenticación Simulada:** Módulos de "Sign in" y "Log in" integrados para simular el acceso de usuarios.
* **Navegación Completa:** Enlaces de soporte, políticas de términos, libro de reclamaciones ficticio y pie de página personalizado.

---

## 🛠️ Tecnologías Utilizadas
* **HTML5:** Estructura semántica de la tienda y páginas informativas.
* **CSS3:** Estilos personalizados orientados a la estética retro clásica (paletas de colores de época, tipografías y maquetación estructurada).
* **JavaScript:** Lógica de interacción dinámica, gestión del carrito y simulación del autenticador de cuentas.
